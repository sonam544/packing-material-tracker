# Packing Material Tracker

Vite + React + TypeScript inventory tracker generated with Qwen Coder.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

The production build is generated in `dist/`.

## Deploy

This project is ready for Vercel deployment. Import the GitHub repository into Vercel and use the default Vite settings:

- Build command: `npm run build`
- Output directory: `dist`
